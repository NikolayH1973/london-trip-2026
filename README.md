# Лондон на Рождество — карманный гид

Неофициальное веб-приложение для участников тура «Лондон на Рождество»
(Метрополь-Каспи, 3–9 декабря 2026, гид Алекс Табак).

## Что умеет

- **Сегодня** — план текущего дня, время и место сбора, кнопка «Написать гиду»; до поездки — обратный отсчёт и прогресс сборов.
- **Программа** — все 7 дней, опции за доплату отмечены отдельно.
- **Места** — главный экран с полками (Рождественские ярмарки · Места программы — по дням, прошедшие с ✅, во время поездки первой и прокручена к сегодня · Первый вечер / Сегодня вечером · Рядом с отелем · Бесплатно), плитками «Что рядом со мной» и «Схема метро» и кнопками категорий. 50 мест: компактный список → карточка места («На карте», «Как добраться», схема маршрута на метро по полю `route`, часы, советы для фото). «Что рядом со мной» объясняет, зачем нужна геолокация, до первого запроса разрешения.
- **Рядом со мной** — кнопка вверху «Мест»: геолокация + координаты мест (`ll`), сортировка по расстоянию (гаверсинус × 1,25), работает без интернета; вне Лондона — режим «как будто я у отеля».
- **Погода** — одна строка у каждого дня (Open-Meteo, 16 дней, без ключа); прогноз кэшируется в `localStorage` и показывается офлайн с пометкой времени; дни дальше 7 — «предварительно».
- **Я потерялся** — адрес отеля, «Показать таксисту», важные телефоны.
- **Отель** — Novotel London West (Хаммерсмит, 2-я зона). «Схема метро» — три линии от отеля без пересадок (`TOUR.lines`): Piccadilly и District со станции Hammersmith, H&C/Circle — со второй станции Hammersmith через дорогу. Маршрут каждого места — поле `route` (`[линия, остановок, станция, пометка]`); если его нет, берётся `direct` по Piccadilly.
- **Полезное** — конвертер £ ↔ ₪, чек-лист сборов, советы.
- **Разговорник** (`#phrases`, вход из «Полезного») — вежливые британские фразы по 7 темам (включая аптеку и здоровье), с произношением, озвучкой (`speechSynthesis`, голос en-GB) и показом крупно на весь экран.

## Устройство

Статический сайт без сборки и без сервера: HTML + CSS + JavaScript.

```
index.html            всё приложение
sw.js                 Service Worker — офлайн-режим
manifest.json         «паспорт» приложения для установки на экран телефона
icon-192/512.png      иконки приложения
apple-touch-icon.png  иконка для iPhone
```

- Все данные тура — в объекте `TOUR` в начале `<script>`. Код ниже ничего не знает про Лондон и только рисует эти данные. Для другого тура меняется только `TOUR`.
- «Сегодня» считается по лондонскому времени (`Intl.DateTimeFormat` с `timeZone: "Europe/London"`).
- Чек-лист и курс валюты сохраняются в `localStorage` — только на устройстве пользователя.
- Офлайн-режим: `sw.js` по стратегии «сначала сеть (таймаут 3 с), потом кэш». С интернетом всегда свежая версия, без интернета — последняя сохранённая. При изменении списка файлов в `sw.js` поднимите версию `CACHE`.
- Навигация по вкладкам — через `#hash` (`#today`, `#program`, `#places`, `#help`, `#tools`). Внутри «Мест» — под-экраны: `#places/cat/pub`, `#places/shelf/eve`, `#places/p/12`, `#places/metro`, `#places/near`; системная кнопка «назад» работает сама.

## Приватность

В файле есть номер телефона гида. Держите репозиторий **приватным**, пока гид не согласился на публикацию.

## Статус рейса (BA405 / BA404)
- Карточка «✈️ Статус рейса» на экране «Сегодня»: до поездки, в день 1 (BA405) и в день 7 (BA404).
- Данные — Aviationstack (бесплатный план, 100 запросов в месяц) через посредника `netlify/functions/flight.mjs` (адрес `/api/flight?f=BA405`).
- Ключ хранится только в Netlify: Site configuration → Environment variables → `AVIATIONSTACK_KEY`. В коде и на GitHub его нет.
- Экономия лимита: посредник отвечает только про наши рейсы, к Aviationstack обращается от 12 ч до вылета до +9 ч, ответ кэшируется Netlify на 30 минут для всех.

## Запись на опции (Google-форма)
- Форма «Лондон: запись на опции» в Google-аккаунте Николая; ответы — в таблице «Лондон: записи на опции», у гида доступ «Редактор».
- В приложении — обычная ссылка на форму (`TOUR.signupForm`): в блоке опций и в каждой опции. В форме можно отметить сразу несколько экскурсий.
- 4 опции (Виндзор, Тауэр, Британский музей, Стратфорд и Оксфорд). Цены — `price: { adult, child }` в фунтах, ребёнок до 16 лет; входные билеты включены. Запись заранее, оплата гиду в первый вечер (£, $ или €).
- Названия экскурсий в форме должны совпадать с приложением — иначе в таблице будет путаница.
- Приложение не знает, кто записан: повторы ловит подсветка дублей в таблице.
