# Лондон на Рождество — карманный гид

Неофициальное веб-приложение для участников тура «Лондон на Рождество»
(Метрополь-Каспи, 3–9 декабря 2026, гид Алекс Табак).

## Что умеет

- **Сегодня** — план текущего дня, время и место сбора, кнопка «Написать гиду»; до поездки — обратный отсчёт и прогресс сборов.
- **Программа** — все 7 дней, опции за доплату отмечены отдельно.
- **Места** — схема ветки Piccadilly от отеля (станции раскрываются: места рядом и пересадки) и 39 мест (с советами для фото у 24) со схемой маршрута на метро (поле `route`, проверено по расписаниям TfL): достопримечательности, бесплатные музеи, ярмарки, смотровые площадки, еда, блошиные рынки. У каждого — «На карте» (Google / Apple) и «Как добраться на метро».
- **Рядом со мной** — кнопка вверху «Мест»: геолокация + координаты мест (`ll`), сортировка по расстоянию (гаверсинус × 1,25), работает без интернета; вне Лондона — режим «как будто я у отеля».
- **Я потерялся** — адрес отеля, «Показать таксисту», важные телефоны.
- **Полезное** — конвертер £ ↔ ₪, чек-лист сборов, советы.
- **Разговорник** (`#phrases`, вход из «Полезного») — вежливые британские фразы по 7 темам (включая аптеку и здоровье), с произношением, озвучкой (`speechSynthesis`, голос en-GB) и показом крупно на весь экран.

## Устройство

Статический сайт без сборки и без сервера: HTML + CSS + JavaScript.

```
index.html            всё приложение
sw.js                 Service Worker — офлайн-режим
manifest.json         «паспорт» приложения для установки на экран телефона
icon-192/512.png      иконки приложения
apple-touch-icon.png  иконка для iPhone
```

- Все данные тура — в объекте `TOUR` в начале `<script>`. Код ниже ничего не знает про Лондон и только рисует эти данные. Для другого тура меняется только `TOUR`.
- «Сегодня» считается по лондонскому времени (`Intl.DateTimeFormat` с `timeZone: "Europe/London"`).
- Чек-лист и курс валюты сохраняются в `localStorage` — только на устройстве пользователя.
- Офлайн-режим: `sw.js` по стратегии «сначала сеть (таймаут 3 с), потом кэш». С интернетом всегда свежая версия, без интернета — последняя сохранённая. При изменении списка файлов в `sw.js` поднимите версию `CACHE`.
- Навигация по вкладкам — через `#hash` (`#today`, `#program`, `#places`, `#help`, `#tools`).
